# Deployment

This project is a standard TanStack Start + React + Vite application.

## Local development

```powershell
npm install
npm run dev
```

## Production build

```powershell
npm run build
```

## Included files

- Resume: `public/resume/Pranjal-Mondal-Resume.pdf`
- Project archive: `public/projects/multi-client-chat.zip`
- Portfolio data: `src/config/portfolio.ts`

https://github.com/mondalpranjal28-sketch/Multi-client-chat-application

## Custom domain

Use a custom domain through your hosting provider if you want a public address with your own name (for example, `pranjalmondal.dev`). The domain is controlled by the hosting provider, not by the source code.
