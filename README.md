# Pranjal Mondal — Developer Portfolio

A futuristic, responsive personal portfolio for Pranjal Mondal, a Computer Science & Engineering student at Jadavpur University and Full-Stack Web Developer.

## Included

- About, skills, education and journey
- Full-Stack/backend technology stack
- Multi-Client Chat Application project
- Direct project ZIP download
- GitHub repository link
- Real resume PDF with View/Download actions
- AI/ML interests
- Data analytics and finance/economics interests
- GitHub activity section
- Contact details
- Responsive mobile/desktop design
- SEO metadata and accessibility-friendly UI

## Run locally

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Main files

- `src/config/portfolio.ts` — personal profile, links, skills and project data
- `public/resume/Pranjal-Mondal-Resume.pdf` — resume
- `public/projects/multi-client-chat.zip` — downloadable Multi-Client Chat project

The LinkedIn URL is intentionally left unconfigured until a verified profile URL is supplied.
